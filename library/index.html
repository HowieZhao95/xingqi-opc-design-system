维护指南

目录从制作源码生成。新增独立样例时，登记一个 HTML 和一条目录记录。

改已有样例

品牌与规范
tokens.json 管理颜色、字体、网格和节奏。基础规范说明在 library/catalog.json。
网页与汇报
web/recipes.json 管理网页组件参数，source/slides.json 管理汇报版式。
MG 与 UHD
motion/shot-plan.json 管理基础镜头，hud-mg/catalog.json 管理光学组件。空间锚点和采样在 source/uhd-scenes.json 与 source/lightfield-data.json。

登记一个独立 HTML

把可离线打开的文件放在 library/examples/，将下列记录追加到 library/catalog.json 的 additional 数组。路径前半段对应左侧分类，条目 ID 会成为可分享的定位地址。

{
  "id": "web/material-note",
  "name": "材料说明",
  "description": "列出一件作品的材料与出处。",
  "page": "examples/material-note.html",
  "tags": ["材料", "出处"]
}

校验与打包

在 OPCPPT V/v3-source/ 运行。第一条在临时目录校验条目、规范锚点和本地文件。第二条重建 HTML 和可分享的 ZIP。基础 MG 的分镜或绘制源码有改动时，先运行 python3 motion/build-standalone.py。

python3 source/build.py --check
python3 source/build.py ./publish --package ./星启OPC-全HTML.zip
